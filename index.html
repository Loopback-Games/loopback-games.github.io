    A whole table in a browser tab

    Looplings

    Procedurally generated puzzling

    Guide small, single-minded creatures to the exit on a budget of eight skills. Every level is generated, then solved by the game before you ever see it, so you are never handed one that cannot be won. Twenty-two kilobytes, gzipped.

  • /solitaire

    Solitaire

    Klondike, dealt by a stylesheet

    Every card face, pip layout and the cascade you get for winning is a CSS rule; the JavaScript only tracks which card sits where. Drag with a mouse, tap-and-tap on a phone, or play the whole thing on Tab and Enter. Add a deal number to the URL to replay a shuffle exactly.
